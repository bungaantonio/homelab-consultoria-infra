# 01 - Contexto e Objetivo

Este projeto documenta um laboratório de estudo para simular uma infraestrutura corporativa pequena, mas organizada, para a empresa fictícia **HomeLab Consultoria & Contabilidade**.

## Contexto de negócio

A organização foi pensada para ter necessidades reais de:

- consultoria e gestão de projetos;
- contabilidade, fiscalidade e relatórios internos;
- controlo de acesso a documentos e pastas;
- separação entre utilizadores comuns, administração e serviços técnicos.

## Objetivo do laboratório

O laboratório pretende mostrar como uma infraestrutura de TI pode ser organizada em torno de três pilares:

1. identidade e autenticação;
2. acesso a recursos e partilhas;
3. segurança e controlo administrativo.

## O que já está documentado

- base de rede e segmentação;
- domínio Active Directory e estrutura lógica;
- desenho de autorização por grupos;
- políticas de segurança e hardening base.
