# 05 - Segurança e Políticas

A segurança do laboratório é tratada como uma camada separada da infraestrutura, mas integrada ao desenho global do projeto.

## Princípios adotados

- princípio do menor privilégio;
- separação entre administração e utilização normal;
- políticas de segurança aplicadas via GPO;
- isolamento da rede por VLANs e regras de firewall.

## Estado atual

O projeto já documenta uma base de:

- políticas de segurança e hardening;
- controlo de acesso por grupos;
- regras de firewall e segmentação;
- fundamentos para futuras melhorias, como LAPS, BitLocker e monitorização.
